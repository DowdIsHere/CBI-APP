                          3 SIMPLE STEPS TO SUCCESS

Step 1: Open Command Prompt
    - Press Windows key + R
    - Type: cmd
    - Press Enter

Step 2: Run This Command
    Copy and paste this into Command Prompt:

    cd C:\ATP\CBI-App && build-android.bat

    Press Enter

Step 3: Wait & Install
    - Wait 10 minutes for build
    - Download APK from link
    - Send to phone
    - Install APK
    - DONE! Icon appears on home screen!

                            CUSTOMIZE THE ICON

Before building, want a custom icon?

1. Open in browser: C:\ATP\CBI-App\create-icons.html
2. Download the icon files
3. Put them in: C:\ATP\CBI-App\assets\
4. Run build command

================================================================================

                            TROUBLESHOOTING

Problem: "eas command not found"
Solution: npm install -g eas-cli

Problem: "Not logged in"
Solution: eas login (create free account)

Problem: "Can't install on phone"
Solution: Settings → Security → Unknown Sources ON
